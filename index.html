Pengertian algoritma routing

Algoritma routing adalah seperangkat aturan dan prosedur yang digunakan dalam jaringan komputer untuk menentukan jalur terbaik bagi paket data dari sumber ke tujuan.

Komponen vital

Routing merupakan komponen vital dalam protokol jaringan karena memengaruhi:

EfisiensiKecepatanKeandalan

Meminimalkan biaya transmisi

Serta menghindari kemacetan atau kegagalan jaringan. Biaya transmisi seperti:

WaktuJarakJumlah hop

APengertian

Routing statis dan dinamis

Routing dapat bersifat statis atau dinamis.

Routing statis

Rute ditentukan secara manual dan tidak berubah.

Routing dinamis

Rute diperbarui otomatis mengikuti perubahan kondisi jaringan.

APengertian

Tahapan proses routing

Proses routing meliputi beberapa tahap utama:

  1. 1

    Pengumpulan informasi

    Informasi jaringan seperti topologi, biaya jalur, dan status node.

  2. 2

    Perhitungan rute terbaik

    Menggunakan algoritma tertentu, misalnya Dijkstra atau Bellman-Ford.

  3. 3

    Pemutakhiran tabel routing

    Struktur data yang menyimpan rute ke berbagai tujuan.

  4. 4

    Penerusan paket

    Paket data diteruskan sesuai informasi dalam tabel routing.

BTujuan

Tujuan penggunaan algoritma routing

Tujuan utamanya adalah meningkatkan efisiensi, kecepatan, dan keandalan dalam pengiriman data.

Data dapat memanfaatkan jalur alternatif yang lebih optimal.

Mengatur lalu lintas data

Lalu lintas diatur agar tidak terjadi benturan atau penundaan yang merugikan.

DAlgoritma populer

Dijkstra (Shortest Path First)

Metode pencarian jalur terpendek dari satu simpul sumber ke semua simpul lain dalam sebuah jaringan.

Prinsip greedy

Selalu memilih jalur dengan bobot terkecil di setiap langkahnya.

OSPFSangat efektif dalam protokol routing OSPF (Open Shortest Path First), terutama pada jaringan menengah hingga besar, selama bobot antar simpul bersifat positif.
Sumber: Komdat P10.pdf, hlm. 4

DAlgoritma populer

Langkah kerja Dijkstra

  1. 1

    Inisialisasi jarak semua node ke tak hingga (∞), kecuali node asal yang diatur ke 0.

  2. 2

    Tandai semua node sebagai belum dikunjungi.

  3. 3

    Pilih node dengan jarak terkecil dari yang belum dikunjungi, lalu kunjungi semua tetangganya.

  4. 4

    Jika ditemukan jalur lebih pendek ke tetangga tersebut, perbarui jaraknya.

  5. 5

    Tandai node tersebut sebagai sudah dikunjungi.

  6. 6

    Ulangi proses ini hingga semua node telah dikunjungi.

Hasil akhir: jalur terpendek dari node sumber ke setiap node lain dalam jaringan.

Sumber: Komdat P10.pdf, hlm. 4

Contoh Dijkstra

Tujuannya adalah mencari jalur terpendek dari A ke D.

  1. Dari A, pilih ke Bjarak 2
  2. Dari B, pilih ke Ctambahan 1, total 3
  3. Dari C, pilih ke Dtambahan 2, total 5
A → B → C → D5jalur terpendek, total bobot 5

DAlgoritma populer

Kelebihan dan keterbatasan Dijkstra

Dijkstra menjadi pilihan utama dalam berbagai sistem jaringan, dengan satu syarat: bobot antar simpul harus positif.

Jalur paling efisien, secara pasti

Selama bobot antar simpul bernilai positif.

Ideal untuk link stabil

Jaringan internal perusahaan dan backbone ISP.

Tidak untuk bobot negatif

Hasil perhitungan menjadi tidak akurat.

Berat di jaringan sangat besar

Banyak perhitungan dan penyimpanan data.

Sumber: Komdat P10.pdf, hlm. 6

DAlgoritma populer

Bellman-Ford

Berbeda dari Dijkstra, Bellman-Ford dapat menangani bobot negatif. Jarak ke semua node diperbarui secara iteratif berdasarkan info dari node tetangga.

Langkah kerja

  1. 1

    Update jarak semua edge sebanyak (jumlah node − 1) kali.

  2. 2

    Jika jarak baru lebih pendek, lakukan pembaruan.

  3. 3

    Cek loop negatif dengan satu iterasi tambahan.

RIPRouting Information Protocol

Kelebihan

  • Mampu menangani bobot negatif
  • Lebih sederhana dan mudah diimplementasikan

Kelemahan

  • Konvergensi lebih lambat (iterasi n − 1 kali)
  • Rentan routing loop; perlu split horizon atau hold-down timer
Sumber: Komdat P10.pdf, hlm. 6–8

DAlgoritma populer

Contoh Bellman-Ford

A —(4)→ BA —(5)→ CB —(−2)→ C

Dari A:

  1. Langkah 1A → B = 4, A → C = 5
  2. Langkah 2B → C = 4 + (−2) = 2

2 lebih pendek dari 5, maka jarak ke C di-update.

A → B → C2hasil terbaik, jarak = 2

DAlgoritma populer

Floyd-Warshall

Menemukan jalur terpendek antar semua pasangan node. Cocok untuk simulasi topologi tertutup, tabel full-matrix antar router, atau jaringan lokal skala kecil.

Prinsip kerja

  1. a

    Bangun matriks jarak awal.

  2. b

    Iterasi menggunakan node sebagai perantara.

  3. c

    Jika jarak(i,j) > jarak(i,k) + jarak(k,j), update jaraknya.

O(n³)Kompleksitas waktu

Kelebihan

  • Info jalur lengkap antar semua node, secara serentak
  • Akurat; cocok untuk sistem dengan topologi tetap

Kekurangan

  • Perhitungan naik drastis seiring jumlah node
  • Tidak disarankan untuk jaringan besar atau sering berubah
Sumber: Komdat P10.pdf, hlm. 8–10

DAlgoritma populer

Flooding

Semua paket disebarkan ke seluruh jalur yang tersedia. Router mengirim salinan paket ke semua antarmuka, kecuali ke arah asal.

Contoh: jika A terhubung ke B dan C, A mengirim ke B dan C sekaligus. B dan C mengirim lagi ke node lainnya, terus menyebar.

Kelebihan

  • Data pasti sampai ke tujuan
  • Tanpa perhitungan rute atau tabel routing

Kekurangan

  • Duplikasi paket, ledakan lalu lintas
  • Membebani bandwidth

Penggunaan

  • Pemancaran awal info routing
  • Kondisi darurat, tabel rute belum ada
Sumber: Komdat P10.pdf, hlm. 10–11

DAlgoritma populer

Random Routing

Memilih jalur pengiriman secara acak dari semua rute yang tersedia, tanpa mempertimbangkan delay, jumlah hop, atau bandwidth.

Contoh: jika A terhubung ke B, C, dan D, A bisa memilih secara acak salah satunya untuk meneruskan paket.

Keunggulan

  • Sangat mudah diimplementasikan
  • Tanpa tabel routing, hemat sumber daya

Keterbatasan

  • Tidak menjamin rute efisien
  • Delay tinggi, looping, paket hilang

Penggunaan

  • Simulasi dan jaringan eksperimental
  • Pengujian perilaku jaringan
Sumber: Komdat P10.pdf, hlm. 11–12
