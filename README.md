# Algoritma Routing — Komunikasi Data, Pertemuan 10

Presentasi web interaktif (20 slide) untuk Bab X Algoritma Routing.

## Navigasi

| Tombol | Fungsi |
|---|---|
| → / Spasi | Slide berikutnya |
| ← | Slide sebelumnya |
| G | Semua slide (overview) |
| F | Layar penuh |
| T | Mode terang / gelap |
| H | Sembunyikan dock |
| M | Matikan / nyalakan animasi |

Animasi selalu aktif secara default, juga di laptop Windows yang mematikan "Animation effects".

Efek refraksi Liquid Glass tampil penuh di Chrome dan Edge.

## Build

```bash
node build.mjs
```

Sumber slide ada di `src/` dan hasil build ditulis ke `index.html`.
